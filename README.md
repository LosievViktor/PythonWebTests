# WebTests (Python)

Python code examples for Web UI Automation Tests made with Playwright library.

## How to launch

1. Create and activate a virtual environment (recommended):

   ```
   python -m venv .venv
   .venv\Scripts\activate
   ```

2. Install dependencies:

   ```
   pip install -r requirements.txt
   ```

3. Install Playwright browsers:

   ```
   playwright install
   ```

4. Run the tests:

   ```
   pytest
   ```
